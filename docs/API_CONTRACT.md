## 1. General rules

| Rule | Value |
|---|---|
| Base URL (local) | `http://localhost:8000/api` |
| Format | JSON, UTF-8 (Urdu text must round-trip unchanged) |
| Interactive docs | `http://localhost:8000/docs` (Swagger, generated by FastAPI) |
| Auth | None in FYP-1 (login and agency roles are FYP-2) |
| CORS | `http://localhost:5173` (Vite dev server) |
| Timestamps | ISO 8601 in UTC, e.g. `2026-11-28T15:02:11Z` |
| IDs | Integers |
| Secrets | Never sent to or stored in the frontend |

### Allowed values (enums)

| Field | Values |
|---|---|
| `platform` | `linkedin`, `instagram`, `x` |
| `language_mode` | `en` (English), `ur` (Urdu script), `roman_ur` (Roman Urdu / mixed) |
| `language_preference` (brand) | `en`, `ur`, `roman_ur`, `mixed` |
| `objective` | `awareness`, `engagement`, `lead_generation`, `sales`, `announcement` |
| run `status` | `success`, `partial`, `failed` |
| `publish_status` | `draft`, `simulated` (FYP-1 never uses `published`) |
| `score.status` | `experimental` (always, in FYP-1) |

### Error format

Our own errors:

```json
{"detail": {"code": "not_found", "message": "Brand 9 not found"}}
```

| HTTP | `code` | When |
|---|---|---|
| 404 | `not_found` | Unknown brand, campaign or post id |
| 409 | `conflict` | Duplicate (e.g. same annotator labels the same post twice) |
| 502 | `timeout`, `rate_limited`, `auth_failed`, `invalid_response`, `unavailable` | LLM provider failure (run is still saved as `failed`) |

FastAPI's own validation errors (HTTP 422) keep FastAPI's shape — the frontend must handle both:

```json
{"detail": [{"loc": ["body", "language_mode"], "msg": "Input should be 'en', 'ur' or 'roman_ur'", "type": "literal_error"}]}
```

## 3. Endpoint details

### E1 `GET /health`

Response `200`:

```json
{"status": "ok", "db": "ok"}
```

`db` is `"unavailable"` if PostgreSQL cannot be reached; the endpoint itself still returns 200.

### E2 `POST /brands` · E5 `PUT /brands/{id}`

Request:

```json
{
  "name": "Chai Junction (fictional demo)",
  "industry": "Food & beverage",
  "audience": "Students and young professionals in Lahore",
  "tone": ["warm", "playful"],
  "language_preference": "roman_ur",
  "guidelines": "Short sentences. Mention Lahore. Max 2 emojis.",
  "prohibited_phrases": ["cheapest", "guaranteed"],
  "example_posts": [
    {"platform": "instagram", "text": "Barish aur chai = perfect shaam ☕ Aaj hi aayein!"}
  ]
}
```

| Field | Required | Rules |
|---|---|---|
| `name`, `industry`, `audience` | Yes | 1–200 characters |
| `tone` | No | List of strings, default `[]` |
| `language_preference` | Yes | Enum above |
| `guidelines` | No | Up to 5,000 characters |
| `prohibited_phrases` | No | List of strings, default `[]` |
| `example_posts` | No | 0–10 items, each `platform` + `text` (1–3,000 chars) |

Response `201` (POST) / `200` (PUT) — the brand as stored:

```json
{
  "id": 1,
  "name": "Chai Junction (fictional demo)",
  "industry": "Food & beverage",
  "audience": "Students and young professionals in Lahore",
  "tone": ["warm", "playful"],
  "language_preference": "roman_ur",
  "guidelines": "Short sentences. Mention Lahore. Max 2 emojis.",
  "prohibited_phrases": ["cheapest", "guaranteed"],
  "example_posts": [
    {"id": 1, "platform": "instagram", "text": "Barish aur chai = perfect shaam ☕ Aaj hi aayein!"}
  ],
  "created_at": "2026-11-24T10:00:00Z",
  "updated_at": "2026-11-24T10:00:00Z"
}
```

### E3 `GET /brands`

Response `200`: list of brand summaries.

```json
[{"id": 1, "name": "Chai Junction (fictional demo)", "industry": "Food & beverage", "language_preference": "roman_ur", "example_count": 5, "created_at": "2026-11-24T10:00:00Z"}]
```

### E4 `GET /brands/{id}`

Response `200`: full brand (same shape as E2 response). `404` if missing.

### E6 `POST /campaigns`

Request:

```json
{
  "brand_id": 1,
  "topic": "Winter menu launch",
  "objective": "awareness",
  "audience": "University students",
  "key_message": "New winter drinks from 1 Dec",
  "cta": "Visit any branch this weekend",
  "platforms": ["linkedin", "instagram", "x"],
  "language_mode": "en"
}
```

| Field | Required | Rules |
|---|---|---|
| `brand_id` | Yes | Must exist (else 404) |
| `topic`, `key_message` | Yes | 1–500 characters |
| `objective` | Yes | Enum above |
| `audience`, `cta` | No | Up to 500 characters |
| `platforms` | Yes | 1–3 unique values from the platform enum |
| `language_mode` | Yes | Enum above |

Response `201`: the campaign with `id`, all fields, `created_at`, and `latest_run: null`, `runs: []`.

### E7 `GET /campaigns?brand_id=1`

Response `200`:

```json
[{"id": 3, "brand_id": 1, "brand_name": "Chai Junction (fictional demo)", "topic": "Winter menu launch", "language_mode": "en", "latest_run_status": "success", "created_at": "2026-11-28T14:55:00Z"}]
```

### E8 `GET /campaigns/{id}`

Response `200`:

```json
{
  "id": 3,
  "brand_id": 1,
  "brand_name": "Chai Junction (fictional demo)",
  "topic": "Winter menu launch",
  "objective": "awareness",
  "audience": "University students",
  "key_message": "New winter drinks from 1 Dec",
  "cta": "Visit any branch this weekend",
  "platforms": ["linkedin", "instagram", "x"],
  "language_mode": "en",
  "created_at": "2026-11-28T14:55:00Z",
  "latest_run": { "...": "GenerationRun object, section 4" },
  "runs": [
    {"id": 7, "language_mode": "en", "status": "success", "created_at": "2026-11-28T15:02:11Z"},
    {"id": 8, "language_mode": "roman_ur", "status": "partial", "created_at": "2026-11-28T15:10:40Z"}
  ]
}
```

To view an older run: `GET /campaigns/{id}?run_id=7` returns that run as `latest_run`.

### E9 `POST /campaigns/{id}/generate`

Request body (optional):

```json
{"language_mode": "roman_ur"}
```

If omitted, the campaign's own `language_mode` is used.

Response `200`: a **GenerationRun** (section 4).
Response `502`: provider failure — error body as in section 1. The run is saved with `status: "failed"` so it appears in `runs`.

Expected time: 5–30 seconds. The frontend must show a loading state and disable the button.

### E10 `PATCH /posts/{id}`

Request:

```json
{"text": "Edited post text...", "hashtags": ["#Lahore", "#WinterMenu"]}
```

Both fields optional; at least one required.

Behaviour: previous text saved to `post_revisions`; `edited` set to `true`; `char_count`, `format_checks` and `score` recomputed.
Response `200`: the updated **GeneratedPost** (section 4).

### E11 `GET /campaigns/{id}/export?format=txt|md|json[&run_id=7]`

Response `200`: file download.

| Format | Content-Type | Content |
|---|---|---|
| `txt` | `text/plain; charset=utf-8` | One block per platform: platform, text, hashtags |
| `md` | `text/markdown; charset=utf-8` | Heading per platform, text, hashtags, score total, line "Score is experimental — DeepDraft FYP-1" |
| `json` | `application/json` | `{"campaign": {...}, "brand_name": "...", "run": {GenerationRun}}` |

Header: `Content-Disposition: attachment; filename=deepdraft_campaign_<id>.<ext>`
Always exports the current (edited, if edited) text.

### E12 `POST /posts/{id}/publish` (stretch)

No request body. Uses `MockPublisher` only.

Response `200`:

```json
{"status": "simulated", "provider": "mock", "external_id": null, "message": "Simulated — not posted to X", "created_at": "2026-12-04T12:00:00Z"}
```

Calling it again on the same post returns the same result (no duplicate). The post's `publish_status` becomes `simulated`.

### E13 `GET /dataset/posts?status=clean&annotator=sohaib&limit=20`

Returns clean posts this annotator has not labelled yet.

```json
[{
  "id": 412, "platform": "instagram", "post_url": "https://www.instagram.com/p/...",
  "account_name": "example_brand", "follower_count": 15200,
  "posted_at": "2026-08-14T09:00:00Z", "snapshot_at": "2026-11-30T18:20:00Z",
  "likes": 840, "comments": 31, "shares": null, "views": null,
  "text": "Azadi mubarak! ...", "language_detected": "roman_ur"
}]
```

### E14 `POST /dataset/posts/{id}/annotations`

Request:

```json
{"annotator": "sohaib", "language_label": "roman_ur", "content_type": "festive", "sentiment": "positive", "notes": ""}
```

| Field | Values |
|---|---|
| `language_label` | `en`, `ur`, `roman_ur`, `mixed` |
| `content_type` | `promotional`, `informational`, `event`, `engagement_question`, `festive`, `hiring_corporate`, `other` |
| `sentiment` | `positive`, `neutral`, `negative` |

Response `201`: the saved annotation with `id` and `created_at`. `409` if this annotator already labelled this post.

### E15 `GET /dataset/stats`

```json
{"total": 640, "by_status": {"raw": 20, "clean": 590, "excluded": 30}, "by_platform": {"linkedin": 180, "instagram": 300, "x": 110}, "annotated_by": {"sohaib": 120, "umair": 120}}
```

## 4. Shared objects

### GenerationRun

```json
{
  "id": 7,
  "campaign_id": 3,
  "language_mode": "en",
  "status": "success",
  "provider": "gemini",
  "model": "<model id from backend .env>",
  "prompt_version": "generate_v1",
  "error": null,
  "latency_ms": 8400,
  "created_at": "2026-11-28T15:02:11Z",
  "posts": [ "GeneratedPost", "GeneratedPost", "GeneratedPost" ]
}
```

When `status` is `failed`: `posts` is `[]` and `error` is `{"code": "rate_limited", "message": "..."}`.
When `status` is `partial`: at least one post failed a hard format check after one retry.

### GeneratedPost

```json
{
  "id": 21,
  "run_id": 7,
  "platform": "x",
  "language_mode": "en",
  "text": "Winter is here, and so are our new drinks...",
  "hashtags": ["#Lahore", "#WinterMenu"],
  "char_count": 214,
  "format_checks": [
    {"rule": "not_empty", "passed": true, "detail": "ok"},
    {"rule": "max_chars", "passed": true, "detail": "214/280"},
    {"rule": "hashtag_count", "passed": true, "detail": "2/3"},
    {"rule": "no_prohibited_phrase", "passed": true, "detail": "none found"},
    {"rule": "cta_present", "passed": true, "detail": "CTA found"},
    {"rule": "language_mode_match", "passed": true, "detail": "detected en"}
  ],
  "score": {
    "total": 74,
    "status": "experimental",
    "dimensions": [
      {"name": "prohibited_phrases", "score": 20, "max": 20, "explanation": "No prohibited phrases found"},
      {"name": "platform_format", "score": 20, "max": 20, "explanation": "All hard checks passed"},
      {"name": "language_mode_match", "score": 15, "max": 15, "explanation": "Detected English as requested"},
      {"name": "brief_coverage", "score": 7.5, "max": 15, "explanation": "CTA present; key message partly covered"},
      {"name": "style_similarity", "score": 11.5, "max": 30, "explanation": "Moderate wording overlap with brand examples"}
    ]
  },
  "edited": false,
  "publish_status": "draft",
  "created_at": "2026-11-28T15:02:11Z",
  "updated_at": "2026-11-28T15:02:11Z"
}
```

`char_count` / `max_chars` count the text plus appended hashtags. Platform limits used: X 280, LinkedIn 3,000, Instagram 2,200 (verify on official help pages; source and date recorded in `docs/DATA_AND_API_PLAN.md`). Hashtag limits (X 3, LinkedIn 5, Instagram 15) are DeepDraft style rules, not platform rules.
